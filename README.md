   # SAFE-VTEAM

   MATLAB framework for variability-aware joint-corner worst-case analysis of VTEAM-based MAGIC logic.

   This repository accompanies the manuscript "SAFE-VTEAM: Variability-Aware Design of
   VTEAM-Based MAGIC Logic via Joint-Corner Worst-Case Analysis" (under review).

   The source code will be released here upon publication of the article.
